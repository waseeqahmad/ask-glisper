# Data

## Demo audit: Lahore Loom (synthetic)

| | |
|---|---|
| What | One AI-search visibility audit of a **fictional** Lahore clothing boutique, Lahore Loom (`lahoreloom.pk`), and four fictional rivals |
| Source | Generated by `scripts/make_demo_data.py` (seed 42). No real engine answers, no real customer, no scraping |
| Licence | Same as this repo |
| Records | `answers.csv` 288 (24 prompts × 4 engines × 3 weekly runs) · `answer_sources.csv` 874 · `answer_mentions.csv` 841 |
| Labelled | every row `capture_method = 'synthetic'`; the app shows "Simulated data" on every answer |
| Shape | the same columns as the flat views Ask Glisper reads inside Glisper (`v_answers`, `v_answer_sources`, `v_answer_mentions`), so the agent SQL is unchanged when it points at real data |

### How it reaches the agent

1. `python3 scripts/make_demo_data.py --load "$GLISPER_DEMO_DB_URL"` writes the CSVs to `data/sample/` and loads them into a
   Postgres database (`ask_glisper_demo`).
2. `python3 scripts/register_zetaris.py` registers that database in Zetaris as data source `GLISPER_DEMO`
   (`CREATE DATASOURCE ... REGISTER DATASOURCE TABLES`, see `scripts/register_zetaris_sources.sql`).
3. The agent queries `GLISPER_DEMO.answers` etc. through the Zetaris query API (SELECT only).
4. `SAMPLE_MODE=true` loads the same CSVs into in-memory sqlite and runs the same SQL, so judges can run it with no services.

### Planted pattern (and why we say so)

The generator plants one pattern so the demo has something real to find: on Perplexity we lose most answers, mostly
to Threadline, and lost answers usually cite the listicle `lahorestyleguide.pk/best-boutiques-lahore-2026` and a
`reddit.com/r/lahore` thread, which won answers rarely cite. Kurta Co wins often on Gemini but only ships in Karachi
(used to show brand memory). Everything else (instagram, dawn.com, daraz.pk, youtube) is random noise, so on engines
other than Perplexity the honest answer is weaker, and the agent says so. The agent is never told the pattern; it
has to find it with SQL, and the Evaluator rejects claims that the rows don't support.

### Limitations

- Synthetic answers are short and templated, so the quotes are one line each.
- Sample size per engine is 72 answers; differences of a few points are noise.
- `scripts/capture_web_search.py` can capture real web-search answers (Groq free tier, labelled `dev_web_search`) for
  a future version; the demo does not use them.
